### Инструменты

`tools/run_lab.ps1` — исправленный драйвер (работает в интерактивной сессии через
`schtasks /IT`). Что исправлено относительно прежней версии:

- один `Add-Type` с классом `W32` вместо двух конфликтующих `Win32`;
- лог пишется только в `driver.log`, в консоль ничего не печатается (раньше строки
  драйвера попадали в кадр);
- снимок — кроп окна консоли (поиск по классу `ConsoleWindowClass` /
  `CASCADING_HOSTING_WINDOW_CLASS`), а не весь рабочий стол;
- отрезается полоса вкладок терминала, изображение апскейлится до 2100 px;
- пауза перед снимком и очистка экрана — кадр соответствует текущей команде;
- очередь читается в кодовой странице консоли (cp866), поэтому кириллица не ломается;
- режимы `@gui` (полный экран) и `@win|<имя процесса>` (снимок окна процесса).

`tools/gui_shots.ps1` — черновик прохода по GUI-утилитам (Process Explorer, Task Manager),
запускается отдельной задачей `lab3gui*` в той же интерактивной сессии.

## Грабли (проверено на практике)

1. `computer_use` управляет только рабочим столом Mac. Внутри Windows агента нет —
   удалённое управление возможно только через задачу в интерактивной сессии (`schtasks /IT`).
2. SSH-сессия живёт в `Session 0` и не видит рабочий стол — снимки экрана оттуда невозможны.
3. `SendKeys` зависит от активной раскладки: при русской раскладке латиница превращается
   в кириллицу. Для ввода текста использовать буфер обмена (`Set-Clipboard` + `Ctrl+V`).
4. `GetConsoleWindow()` в Windows Terminal бесполезен — окно ищется перечислением по классу.
5. Process Explorer: фильтр — `Edit` внутри `ReBarWindow32`; нижняя панель `Ctrl+L`,
   режим Handles `Ctrl+H`, но только когда фокус в дереве (`TreeListWindowClass`).
   Меню через `GetMenu`/`PostMessage` не сработало — PE использует неменюшный интерфейс.
6. `Add-Type`: один класс на скрипт, иначе конфликт типов; ошибки компиляции не видны,
   если не обернуть в `try/catch`.
7. Очередь команд пишется в cp866; `chcp 65001` ставить нельзя — программы через
   `console_ru.h` перекодируют UTF-8 → 866.
8. Task Manager: UIA не находит ни поле поиска, ни вкладки — нужен клик по координатам.
