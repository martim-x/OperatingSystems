# План пересборки ЛР4: полные циклы запуска Windows-приложений

Дата: 2026-11-12. Статус: выполнен.

## 1. Цель

Пересобрать `lab4/lab4.docx` и `lab4/lab4.pdf` так, чтобы Windows-часть опиралась
на новые консольные кадры полного цикла: запуск приложения, работа трёх потоков,
приостановка и возобновление, принудительное завершение, завершение программы.
Каждый этап описывается отдельным абзацем со ссылкой на свой рисунок.

## 4. Этапы

1. Снять резервную копию `report.json`, `lab4.docx`, `lab4.pdf` и каталога
   `build/скрины/windows` в scratch, зафиксировать SHA-256.
2. Обрезать у новых кадров полосу вкладок и пустые поля, сохранить в
   `build/скрины/windows/уровень_4-5/`:
   - `task35_lab04b_cycle_start.png` (`210657`);
   - `task36_lab04b_cycle_suspended.png` (`210720`);
   - `task37_lab04b_cycle_resume.png` (`210729`);
   - `task38_lab04b_cycle_main_end.png` (`210735`);
   - `task39_lab04c_cycle_start.png` (`211215`);
   - `task40_lab04c_cycle_terminate.png` (`211230`).
3. Проверить обрезанные кадры OCR: заголовок, TID, ключевые строки этапов.
4. Переписать в `report.json` подраздел Lab-04b: последовательность
   запуск -> приостановка -> возобновление -> завершение, отдельный рисунок на
   каждый этап, ссылки до рисунков, старые фрагментарные кадры `task22`-`task25`
   и `task24` заменить новыми.
5. Переписать подраздел Lab-04c: запуск -> `TerminateThread` -> работа после ->
   списки потоков -> завершение; новые кадры `task39`/`task40`, старые
   PowerShell- и PE-кадры сохранить как дополнительные доказательства.
6. Сохранить без изменений кадры сборки, Lab-04a, Lab-04d, уровней 7-8 и 9-10,
   а также всю Linux-часть.
7. Собрать отчёт в scratch с `--check --pdf`, проверить число рисунков,
   оглавление, отсутствие `PLACEHOLDER`, длинных тире, прямых кавычек и
   скобочных ссылок на листинги.
8. Отрецдерить страницы Windows-части и проверить читаемость кадров и связку
   «рисунок - подпись».
9. Установить проверенные DOCX/PDF в `lab4/`, обновить `README.md`, `BACKLOG.md`,
   `ТЕХДОЛГ.md` и манифест скринов.
10. Проверить `git status`: изменены только целевые файлы ЛР4.

## 5. Критерии приёмки

- в отчёте для Lab-04b есть отдельные кадры запуска, приостановки,
  возобновления и завершения, все они из одного прогона (PID 7744);
- для Lab-04c есть кадры запуска, принудительного завершения и завершения
  программы;

- кадр сборки остаётся старым `task21`;
- `app build --check` без ошибок, `ogлавление` заполнено полностью;
- `PLACEHOLDER` = 0, `—` = 0, прямых кавычек = 0, `(листинг` = 0;
- число рисунков в PDF, DOCX и `report.json` совпадает.
