## 3. Замеры для сравнительной таблицы

Нужна серия для `Lab-04p.exe` и `Lab-04p2.exe`:

- N = 1, 2, 4, 8, 12 (6 физических ядер, 2N = 12);
- диапазоны: `1 1048576` (2²⁰) и `1 2097152` (2²¹);
- для каждой строки: программа, N, диапазон, найдено простых, время.

Процессный аналог из ЛР3: на Windows готового `Lab-03primes` нет. Варианты:
1. Портировать `lab4/linux/Lab-03primes.c` на WinAPI (`CreateProcess` + анонимный канал) — тогда сравнение будет корректным.
2. Использовать `Lab-03d-server.exe` из ЛР3 с оговоркой: в ЛР3 искали числа, взаимно простые с `M`, а не простые.

Рекомендуется вариант 1, иначе сравнение разных алгоритмов.

## 4. Как снимать

### Консольные кадры

Использовать драйвер `lab4_sync` по образцу `lab3_sync`:
1. Файл `<имя>.cmd` положить в `C:\lab4_sync\queue\` в кодировке **cp866**.
2. Запустить задачу: `schtasks /run /tn lab4drv`.
3. Забрать PNG из `C:\lab4_sync\shots\`, лог — `C:\lab4_sync\driver.log`.

Если драйвера нет, снять вручную: запустить `.exe` в консоли, дождаться нужного момента, снять клиентскую область окна.

### Process Explorer

- ARM64-сборка: `C:\Users\User-6d4ec851\Downloads\ProcessExplorer\procexp64a.exe`.
- Нижняя панель: `View → Show Lower Pane` (`Ctrl+L`).
- Режим Threads: `View → Lower Pane View → Threads`.
- Фокус в дереве процессов — клик по `Lab-04b.exe` / `Lab-04c.exe`, иначе горячие клавиши не работают.
- Для `Lab-04b` кадры снимать в момент, когда главный поток напечатал `>>> Поток 1 приостановлен...` / `>>> Поток 2 приостановлен...`.
- Для `Lab-04c` — до и после строки `>>> Поток 2 завершён принудительно...`.

### Подбор chunk для `Lab-04pi`

Запускать `Lab-04pi.exe 4 <chunk>` на 2–3 секунды, посылать `Ctrl+C`, записывать `Обработано слагаемых`. Серия: 500, 1000, 2000, 5000, 10000, 20000, 50000.

- Не менять `lab4/linux/**`, `lab4/windows/**` (кроме сборки), `lab4/README.md`.
- Не пересобирать отчёт — это делается на Mac.
- Не подменять кадры плейсхолдерами, скриншотами рабочего стола или чужими файлами.
- Не выдумывать содержимое: если кадр снять невозможно — положить честный кадр и написать об этом в отчёте.
- Не использовать `chcp 65001` в скриптах, создающих кириллические имена: консоль остаётся в cp866.
