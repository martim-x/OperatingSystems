# Как принять скрины ЛР3 и пересобрать отчёт

**Машина:** Mac + Windows-ВМ по SSH `User-6d4ec851@192.168.31.23` (должна быть включена и загружена в Windows).
**Что нужно:** 7 PNG по списку из `ТЕХДОЛГ_СКРИНЫ.md` в `C:\lab3_sync\shots\`.

---

## 1. Проверить, что кадры уже на месте

```bash
cd ~/Documents/VisualStudioCodeRepos/OperatingSystems/lab3/windows/tools
python3 integrate_shots.py
```

Печатает по каждому из 7 файлов: `OK` (размер и разрешение), `ждём` (нет файла) или `БРАК` (мельче 100 КБ, уже 2000 px, не PNG).

## 2. Забрать кадры в репозиторий

```bash
python3 integrate_shots.py --apply
```

Копирует по scp в `lab3/windows/скрины/уровень_4-5/` и `уровень_7-8/` под финальными именами. Существующие файлы перезаписываются.

## 3. Дописать фигуры в report.json

```bash
python3 prepare_report_figures.py           # посмотреть, что добавится
python3 prepare_report_figures.py --apply   # записать
```

Скрипт идемпотентный: добавляет только отсутствующие метки и только для кадров, которые реально лежат в репозитории и весят ≥100 КБ. Перед записью делает `report.json.bak`.

Что добавляется:

| Метка | Файл | Куда встаёт |
|---|---|---|
| `fig3_win_13_cmd` | `уровень_4-5/task09_cmd.png` | после блока «три процесса», уровень 4–5 |
| `fig3_win_14_taskmgr` | `уровень_4-5/task10_taskmgr.png` | там же |
| `fig3_win_15_handles_45` | `уровень_4-5/task16_procexp_handles.png` | там же |
| `fig3_win_16_pipe_45` | `уровень_4-5/task15_procexp_pipe.png` | там же |
| `fig3_win_17_pipe_78` | `уровень_7-8/task15_procexp_pipe.png` | после абзаца про дескриптор канала, уровень 7–8 |
| `fig3_win_18_handles_78` | `уровень_7-8/task16_procexp_handles.png` | там же |

`task11_three_proc.png` уже прописан в отчёте отдельным блоком — скрипт его не дублирует, но `integrate_shots.py` его забирает и проверяет.

## 4. Собрать отчёт

```bash
cd ~/Documents/VisualStudioCodeRepos/BstuReportBuilder
/opt/homebrew/bin/python3 -m app build \
  ~/Documents/VisualStudioCodeRepos/OperatingSystems/lab3/build/report.json \
  -o ~/Documents/VisualStudioCodeRepos/OperatingSystems/lab3/build/lab3_built.docx --check
```

Ожидаемая база: 25 картинок; с полным набором новых — **31**. `check` должен дать `exit=0` и ни одного `ERROR`.

---

## Если кадр забракован

1. Не подменять плейсхолдером и не тянуть похожий кадр из `сырые/`.
2. Вернуть исполнителю строку с критерием из `ТЕХДОЛГ_СКРИНЫ.md` (раздел 2) — там для каждого файла сказано, что именно должно быть в кадре.
3. Отчёт собирать с тем набором, что принят; в тексте оставить ссылку только на принятые фигуры (скрипт это и делает — он добавляет фигуру только при наличии файла).
