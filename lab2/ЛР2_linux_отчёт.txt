** 1 ВВЕДЕНИЕ

Операционная система предоставляет пользователю интерфейс взаимодействия с аппаратными ресурсами компьютера. Наиболее эффективным интерфейсом работы в системе является командная оболочка, обеспечивающая выполнение операций над файлами и каталогами, запуск программ и автоматизацию повторяющихся действий.

В настоящей лабораторной работе выполняются задания уровней 4-9 методических указаний для операционной системы Linux. Работа выполнена в дистрибутиве Arch Linux ARM в командной оболочке bash. Все задания Windows-части сопоставлены с соответствующими средствами Linux, что позволяет выполнить единый вариант лабораторной работы на одной операционной системе.

Цель работы - освоить приёмы работы с командной оболочкой и научиться составлять собственные сценарии автоматизации.

Для достижения цели поставлены следующие задачи:
- выполнить задания уровней 4-5 по навигации, копированию, просмотру и удалению файлов;
- выполнить задания уровней 6-7 по расширенному копированию, работе с консольным вводом и выводом, составлению сценариев с параметрами;
- исследовать переменные окружения и определить наиболее значимые из них для работы в консоли;
- выполнить задания уровней 8-9 по подсчёту команд в PATH, выводу дерева каталогов с размерами и мониторингу процессов;

Выполнение всех заданий сопровождалось фиксацией результата: для каждой команды сделан снимок полноэкранной консоли и сохранён текстовый вывод. Полнота выполнения проверена автоматизированным распознаванием текста на снимках.

** 3 СООТВЕТСТВИЕ КОМАНД WINDOWS И LINUX

Каждому заданию Windows-части методических указаний сопоставлено средство Linux, приведённое в таблице 3.1. Изучение отличий в наименовании и поведении команд позволяет освоить перенос типовых операций администрирования на unix-системы.

Таблица 3.1 - Соответствие команд Windows и Linux

Команда Windows | Средство Linux | Отличия и примечания
cd | cd | Совпадает. Переход по абсолютному или относительному пути.
md | mkdir | mkdir -p создаёт и промежуточные каталоги.
rd | rmdir, rm -r | rmdir удаляет только пустой каталог, rm -r - любой.
dir | ls -R | Рекурсивный вывод вложенных элементов.
copy | cp | cp -i запрашивает подтверждение перезаписи.
copy con | cat > file | Ввод с клавиатуры до сигнала конца файла.
move | mv | Совпадает.
ren | mv | Переименование выполняется перемещением.
fc | diff | Вывод различий двух файлов.
del | rm | rm -i запрашивает подтверждение удаления.
xcopy | cp -r | cp -rp сохраняет атрибуты файлов.
replace | cp | Замена файлов копированием с ключом -f.
attrib | chmod | Права доступа задаются в восьмеричной записи.
type | cat | Совпадает.
find | grep | Поиск по содержимому файлов.
echo | echo | Вывод строки, в том числе с перенаправлением.
sort | sort | Совпадает.
systeminfo | uname, cat | Данные о системе читаются из /proc и /sys.
set | env, printenv | env без параметров показывает всё окружение.
bat_01 | bash bat_01.sh | Сценарий получает данные из переменных окружения.
bat_02 | bash bat_02.sh | Расширения параметров заменены на basename и stat.
bat_03 | bash bat_03.sh | Параметры передаются как позиционные ($1, $2, $@).
bat_04 | bash bat_04.sh | Арифметика выполняется командой bc или $(( )).
bat_05 | bash bat_05.sh | Режимы работы задаются первым аргументом.

Наиболее существенные отличия связаны с отсутствием в unix-системах расширенных атрибутов файлов в понимании Windows, с различиями в разделителе элементов пути, в механизмах перенаправления вывода и в системе прав доступа, построенной на владельце, группе и других.

|| А.2 Сценарий получения сведений о файле сценария (аналог bat_02)

```
#!/bin/bash
# bat_02.sh — аналог bat_02.bat: имя скрипта, время изменения, полный путь
# Аналоги bat: %~nx0 (имя файла), %~t0 (дата изменения), %~f0 (полный путь)

echo "Изменён: $(stat -c '%y' "$0" | cut -d'.' -f1)"

```

|| А.3 Сценарий работы с параметрами командной строки (аналог bat_03)

```
#!/bin/bash
# bat_03.sh — аналог bat_03.bat: все параметры и первые четыре по отдельности
# Аналоги bat: %* (все), %1..%4 (по отдельности)

echo "=== bat_03: параметры ==="
echo "Все параметры: $*"
```

```
        exit 1
```
```
        ;;
```

```
#!/bin/bash
# path_count.sh — подсчёт исполняемых и неисполняемых команд в PATH (уровень 8)
```

|| А.7 Сценарий вывода дерева каталогов с размерами файлов в десятичных и двоичных единицах

```
#!/bin/bash
# tree_sizes.sh — вывод дерева каталогов с размерами (уровень 8)
# Для каталогов — число файлов; для файлов — размер в KB/MB/GB и KiB/MiB/GiB
# Использование: ./tree_sizes.sh [каталог]   (по умолчанию текущий)

target="${1:-.}"

# Размер в десятичных единицах: KB = 1000 байт
fmt_dec() {
    awk -v b="$1" 'BEGIN {
        if (b < 1000)          printf "%d B", b
        else if (b < 1000000)   printf "%.2f KB", b/1000
        else if (b < 1000000000) printf "%.2f MB", b/1000000
        else                   printf "%.2f GB", b/1000000000
    }'
}

# Размер в двоичных единицах: KiB = 1024 байт
fmt_bin() {
    awk -v b="$1" 'BEGIN {
        if (b < 1024)            printf "%d B", b
        else if (b < 1048576)    printf "%.2f KiB", b/1024
        else if (b < 1073741824) printf "%.2f MiB", b/1048576
        else                     printf "%.2f GiB", b/1073741824
    }'
}

echo "================================================================"
echo " ДЕРЕВО КАТАЛОГОВ: $target"
echo " Формат размера файла: <десятичный> / <двоичный>"
echo "================================================================"
printf "%s[DIR ] %-40s файлов: %s, размер: %s / %s\n" "$2" "." "0" "0 B" "0 B"

print_tree() {
    local dir="$1" indent="$2"
    local fcount=0 tsize=0

    # Считаем рекурсивно по текущему каталогу
    while IFS= read -r -d '' f; do
        if [ -f "$f" ]; then
            fcount=$((fcount + 1))
            tsize=$((tsize + $(stat -c%s "$f")))
        fi
    done < <(find "$dir" -type f -print0 2>/dev/null)

    local dsize dec_size bin_size
    dsize=$(fmt_dec "$tsize")
    bin_size=$(fmt_bin "$tsize")
    printf "%s[DIR ] %-40s файлов: %d, размер: %s / %s\n" "$indent" "$(basename "$dir")" "$fcount" "$dsize" "$bin_size"

    local item name
    for item in "$dir"/* "$dir"/.[!.]*; do
        [ -e "$item" ] || continue
        name=$(basename "$item")
        if [ -d "$item" ]; then
            print_tree "$item" "$indent  "
        else
            local sz szd szb
            sz=$(stat -c%s "$item")
            szd=$(fmt_dec "$sz")
            szb=$(fmt_bin "$sz")
            printf "%s[FILE] %-40s %s / %s\n" "$indent  " "$name" "$szd" "$szb"
        fi
    done
}

print_tree "$target" ""
echo "================================================================"
```

```
#!/bin/bash
# top5.sh — монитор топ-5 процессов по CPU и памяти (уровень 9)
# Использование: ./top5.sh [интервал_в_секундах]   (по умолчанию 5)
# Работает в бесконечном цикле до Ctrl+C.

INTERVAL="${1:-5}"

if ! [[ $INTERVAL =~ ^[0-9]+$ ]] || [ "$INTERVAL" -eq 0 ]; then
    echo "Ошибка: интервал должен быть положительным целым числом секунд"
    exit 1
fi

trap 'echo; echo "Монитор остановлен."; exit 0' INT TERM

# Итоговая память системы в МБ — для перевода процентов в мегабайты
TOTAL_MB=$(awk '/MemTotal/ {printf "%d", $2/1024}' /proc/meminfo)

fmt_row() {
    printf "%-8s %-24s %8s %10s %8s\n" "$1" "$2" "$3" "$4" "$5"
}

while true; do
    clear
    echo "================================================================"
    echo " МОНИТОР ПРОЦЕССОВ - ТОП-5"
    echo " Время:        $(date '+%Y-%m-%d %H:%M:%S')"
    echo " Интервал:     ${INTERVAL} с (Ctrl+C - выход)"
    echo " Всего памяти: ${TOTAL_MB} МБ"
    echo "================================================================"

    echo
    echo " ТОП-5 ПРОЦЕССОВ ПО ЗАГРУЗКЕ ЦП"
    fmt_row "PID" "ИМЯ" "CPU,%" "ПАМЯТЬ,МБ" "ВРЕМЯ CPU"
    fmt_row "--------" "------------------------" "--------" "---------" "----------"
    ps -eo pid,comm,%cpu,%mem,time --sort=-%cpu 2>/dev/null | head -6 | tail -5 | while read pid comm cpu mem cputime; do
        mbm=$(awk -v p="$mem" -v t="$TOTAL_MB" 'BEGIN{printf "%.1f", p*t/100}')
        printf "%-8s %-24s %8s %10s %8s\n" "$pid" "$comm" "$cpu" "$mbm" "$cputime"
    done

    echo
    echo " ТОП-5 ПРОЦЕССОВ ПО ЗАГРУЗКЕ ОПЕРАТИВНОЙ ПАМЯТИ"
    fmt_row "PID" "ИМЯ" "CPU,%" "ПАМЯТЬ,МБ" "ВРЕМЯ CPU"
    fmt_row "--------" "------------------------" "--------" "---------" "----------"
    ps -eo pid,comm,%cpu,%mem,time --sort=-%mem 2>/dev/null | head -6 | tail -5 | while read pid comm cpu mem cputime; do
        mbm=$(awk -v p="$mem" -v t="$TOTAL_MB" 'BEGIN{printf "%.1f", p*t/100}')
        printf "%-8s %-24s %8s %10s %8s\n" "$pid" "$comm" "$cpu" "$mbm" "$cputime"
    done

    echo
    echo "================================================================"
    sleep "$INTERVAL"
done
```
