# ЛР6, Linux — синхронизация (уровень 4–5)

Оба приложения по умолчанию выполняют 100 итераций с задержкой 100 мс на каждом worker. Общий защищённый ресурс — только итерации 30–60 включительно; прочие итерации могут идти параллельно с этим диапазоном.

- `Lab-06a.c`: главный поток и два созданных потока A/B используют один `pthread_mutex_t`.
- `Lab-06b.c`: родитель и два процесса A/B, созданные `fork()`, используют один безымянный POSIX-бинарный семафор (`sem_init(..., pshared=1, value=1)`) в общей `mmap(MAP_SHARED)` памяти.
- `lab06_common.h`: общая задержка, печать итераций и символов имени пользователя `User-6d4ec851`.

## Сборка и запуск

Из этой папки:

```sh
./build.sh
./build/Lab-06a
./build/Lab-06b
```

Каждый запуск занимает примерно 10–17 секунд. Формат `ITER` включает имя worker, PID, номер итерации и очередной символ имени пользователя. Строки `ENTER`/`LEAVE` отмечают захват/освобождение диапазона 30–60. В обычном терминале все процессы Lab-06b наследуют один stdout; PID позволяет различать их. Программа не запускает терминальный эмулятор и не предполагает наличие рабочего стола (включая WSL/CI).

## Проверка

```sh
python3 test_lab06.py
```

Тесты компилируют оба исходника GCC с `-Wall -Wextra -Werror`, запускают программы и проверяют для каждого worker ровно итерации 1–100, символы имени, три отдельных PID для Lab-06b, а также неперекрытие критических интервалов и присутствие в каждом всех 31 итераций 30–60.
