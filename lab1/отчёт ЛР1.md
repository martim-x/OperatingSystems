## 5. Установка Linux (Arch Linux, без скриптов-установщиков)

Повышенный уровень требует Arch **вручную** (без archinstall/archfi) + dual boot с Windows на одной ВМ.

> **Скриншоты №12–18:** этапы ручной установки Arch.

1. *(скрин)* **Загрузка с ISO** — стартовое меню установочного образа.
2. *(скрин)* **Разметка диска (fdisk/cfdisk)** — созданы разделы: EFI (512 МБ, /boot/efi... у меня /boot), swap (по желанию), корень. *Не задел существующие разделы Windows.*
3. *(скрин)* **Форматирование и монтирование** — `mkfs.fat -F32`, `mkfs.ext4`, `mount`.
4. *(скрин)* **pacstrap** — установка базовых пакетов в целевую систему.
5. *(скрин)* **genfstab, chroot, локаль/часовой пояс** — настройка `/etc/fstab`, `locale.gen`, timezone.
6. *(скрин)* **Установка загрузчика GRUB** — `grub-install`, `grub-mkconfig` — GRUB видит и Windows (os-prober), dual boot готов.
7. *(скрин)* **Первый вход в систему** — приглашение входа, вход под `User-XXXXXXXX`.

## 8. Ответы на вопросы для самоконтроля

*(уровень 7–9: отвечать на 1–12; вопросы 13–16 — только для LFS-уровня, можно не отвечать, но лучше подготовиться к устной защите)*

**1. Что такое ОС?** — комплекс программ, управляющий устройствами компьютера и ресурсами, обеспечивающий интерфейс между пользователем/приложениями и «железом».

**2. Назначение ОС** — управление ресурсами (CPU, память, ввод-вывод), исполнение программ, организация файловой системы, взаимодействие с пользователем.

**3. Состав ОС** — ядро, драйверы, интерфейс (shell/GUI), системные библиотеки, служебные программы.

**4. Функции ОС** — планирование процессов, управление памятью, файловая система, ввод-вывод, защита/разграничение прав, сеть, UI.

**5. Виды ОС** — по назначению: универсальные, реального времени, встраиваемые, серверные; по режиму: пакетные, диалоговые; по ядру: монолитные, микроядерные, гибридные.

**6. POSIX** — семейство стандартов IEEE (1003) для переносимого интерфейса ОС (API, shell, утилиты). Нужен для переносимости программ между UNIX-подобными системами.

**7. Шинная архитектура ЭВМ** — архитектура, в которой все устройства связаны общей магистралью (шиной): CPU ↔ память ↔ контроллеры устройств обмениваются данными по общим линиям адреса/данных/управления.

**8. Компоненты архитектуры** — CPU (исполнение команд), ОЗУ (данные и код), контроллеры/адаптеры (диски, сеть, графика), шина (магистраль обмена), ПЗУ/BIOS (стартовая прошивка), порты ввода-вывода.

**9. Системная шина состоит из:** шины данных (перенос данных), шины адреса (куда), шины управления (сигналы чтения/записи, прерывания).

**10. BIOS vs UEFI** — BIOS: legacy 16-бит прошивка, загрузка с MBR, 1 МБ адресуемого пространства, ограничения 2.2 ТБ. UEFI: современная прошивка, загрузка по спецификации ESP+загрузчик, GPT, графический интерфейс, модульность, безопасная загрузка (Secure Boot).

**11. Загрузчик** — программа, загружающая ядро ОС с диска в память и передающая ему управление. Windows — Windows Boot Manager (bootmgfw.efi); Linux — GRUB2, также systemd-boot, LILO (устар.).

**12. Dual Boot** — установка двух (и более) ОС на один компьютер с выбором загружаемой системы при каждом старте через загрузчик (GRUB / Windows Boot Manager).
