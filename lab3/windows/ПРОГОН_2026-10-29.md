## Зачем переснимали

Исходники 26.10 приведены к методичке: `Lab-03a` и `Lab-03b` больше **не принимают аргументов командной
строки** (итерации — константа 5 и переменная окружения ITER_NUM). Все прежние кадры и выводы были сняты
**до** этой правки, на сборке с вызовом `Lab-03a.exe 3` / `Lab-03b.exe 3`, и не соответствовали ни
исходникам, ни тексту отчёта.

Дополнительно в исходниках восстановлен русский вывод программ (`console_ru.h` подключается именно для
перекодировки UTF-8 → cp866), из `Lab-03x.c` убран остаток аргумента `--pause`.

## Как переснять заново

```cmd
schtasks /run /tn lab3drv
```

Очередь — `C:\lab3_sync\queue\<NN>_<имя>.cmd` в cp866; результат — `C:\lab3_sync\shots\<NN>_<имя>.png` и
`C:\lab3_sync\done\<NN>.txt`. Скрипт драйвера — `windows/tools/run_lab.ps1`.

## Грабли этого прогона

1. **Команда в очереди не должна порождать процесс, который наследует перенаправление вывода.** `start "" /b prog`
   внутри очереди утащил stdout в `tmp_out.txt`: следующие команды читали чужой вывод и получали пустоту.
   Живые процессы для кадров запускать снаружи очереди, а в очередь ставить только `tasklist`.
2. **`set VAR=value > file` в сгенерированном `.cmd` дописывает в переменную пробел** — печаталось
   `ITER_NUM=5  ,`. Писать `set "ITER_NUM=5"`.
3. **Process Explorer:** окно — класс `PROCEXPLORER`, фильтр — `Edit` в `ReBarWindow32`, список —
   `TreeListWindowClass`. Текст в фильтр подаётся через буфер (`Set-Clipboard` + `Ctrl+V`), поле перед
   вставкой чистится `Ctrl+A`, `Delete`.
4. **Скриншотер должен быть DPI-aware.** Без `SetProcessDPIAware()` окно PE отдаёт 4138x2510, а экран —
   2056x1290: клики уходят мимо, снимок получается сдвинутым.
5. **Нижняя панель PE — `Ctrl+L`, режим Handles — `Ctrl+H`**, работает только когда фокус в дереве;
   сортировка по типу — клик по заголовку `Type` нижней панели.
6. **`GetConsoleWindow()` в Windows Terminal бесполезен** — окно консоли ищется по классам
   `ConsoleWindowClass` / `CASCADING_HOSTING_WINDOW_CLASS`, затем разворачивается и поднимается приёмом
   ALT + TOPMOST с проверкой `GetForegroundWindow()`.
7. **Очередь пишется в cp866**; `chcp 65001` ставить нельзя — программы через `console_ru.h` сами
   перекодируют UTF-8 → 866.
